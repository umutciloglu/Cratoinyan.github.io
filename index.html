Tinkerer. When a new technology catches Umut's interest, Umut builds a small program with it before the next long rest.

Off the Clock. Umut has a riding speed of 120 ft. on a motorcycle, used mostly to reach the next TTRPG session. Between sessions, Umut plays video games.

Actions

Start a Hobby Project. Umut picks a new technology and opens an empty repository. The project gains 1d20 commits of pure enthusiasm.

Abandon the Hobby Project (Recharge 5–6). The repository goes silent. Umut is freed from it and can immediately use Start a Hobby Project again.

Legendary Actions

Umut can take 3 legendary actions, choosing from the options below. Spent actions are regained at the start of each workday.

Drink Coffee. Umut regains 1d8 + 2 focus and has advantage on the next debugging check.
